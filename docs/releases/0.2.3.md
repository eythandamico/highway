# Highway 0.2.3 release notes

Status: local release candidate; publication and deployment remain manual. Date: October 28, 2026.

## Install or upgrade

Upgrade both private tarballs together and retain existing host adapters, handlers and brand tokens:

```sh
npm install --ignore-scripts --save-exact ./vendor/highway/highway-styles-0.2.3.tgz ./vendor/highway/highway-react-0.2.3.tgz
```

Use the first-adoption command only for new integrations; it deliberately refuses upgrades. React and React DOM must remain a matching supported pair (19.2+). No backend or infrastructure migration is required. The companion MCP 0.1.1 bundles the 0.2.3 catalog; rebuild/restart it after upgrading the source checkout.

## Behavior to review

- ExpandCard toggles from its native header button. Actions inside expanded content no longer collapse the card. Collapsed content is inert; dynamic content height is observed.
- Tabs and SliderInput respond immediately to keyboard input. Pointer transitions retain the existing curves/timings; reduced-motion preferences are honored by migrated recipes.
- Strict-null declaration generation now gives previously inferred array props explicit types. TypeScript may expose invalid values formerly hidden by loose inference. Review Table column keys/render callbacks and structured navigation/option props against the returned declarations.
- Toast dismissal timers and scheduled frames are cleaned up on unmount. No global motion-speed normalization or glass-material replacement was made.
- Engineering contracts describe required review states, not blanket certification. The exact inherited-exception inventory remains a migration backlog.

## Validation and rollback

Run `npm run verify:full` in Highway and the consumer's own build/interaction checks. Review keyboard input, rapid reversals, light/dark material, overlay focus, narrow layouts and existing handlers. Automated browser emulation does not certify physical devices or assistive technology.

Keep the previous matched 0.2.2 tarballs/lockfile until host validation passes. Roll back both React and styles together; retain host data and deployment configuration. No migration or data rollback is needed.
