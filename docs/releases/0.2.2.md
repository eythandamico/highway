# Highway 0.2.2 release notes

Status: validated local release candidate, not published or deployed. Date: October 21, 2026.

This release fixes the nine findings in the package quality audit while retaining Highway's materials, motion and approved typography scale. Highlights include keyboard/touch range controls, reliable menu focus, host-safe BottomSheet behavior, more precise types and removal of unused calendar output in minimal builds.

## Install or upgrade

Obtain the matching private release artifacts and place them in your project's versioned vendor/highway directory:

```sh
npm install --ignore-scripts ./vendor/highway/highway-styles-0.2.2.tgz ./vendor/highway/highway-react-0.2.2.tgz
```

For a first adoption from the source checkout, use `npm run adopt -- --target /absolute/project` to preview, then repeat with `--apply`. React and React DOM must already be installed at matching stable supported versions (^19.2.0). CSS-only hosts use `--mode styles`. This command adds files and installs packages; follow the generated integration guide to connect your app.

Do not use the first-adoption command to upgrade an existing Highway integration. Upgrade both packages together, retain the host provider and branding, and commit the new tarballs and lockfile. Remove obsolete vendor artifacts only after the upgrade passes. The installer does not automatically upgrade React or support other package managers/workspaces.

## Behavior to review

- BottomSheet: default host isolation replaces the implicit page shrink. To retain that effect, pass an explicit owned sibling element as pageTarget; keep the sheet outside the transformed target.
- Menus: closed actions cannot receive focus. Escape returns focus; Tab dismisses and continues navigation.
- Tabs: remains a view-button group with aria-pressed, not an ARIA tab/panel abstraction.
- Progress: value 5 / max 10 displays 50%. Reduced motion bypasses the animated count.
- Types: fix invalid callback/option shapes exposed by the new declarations instead of suppressing errors.
- Apply the documented typography roles to custom host content; installing CSS cannot rewrite existing markup or override every host selector.

## Validation and rollback

The package audit records the release-candidate evidence: external installed-consumer types/build/SSR and 20 browser checks; full UI gate 28 checks. Conditional project skips and remaining limits are documented there. These counts describe that validation snapshot, not every future run.

Run the consumer's build and business-flow checks after upgrading; check keyboard, mobile, portals and brand contrast. For rollback, restore both previous package artifacts, package.json and lockfile from the consumer's known-good commit, then npm ci. Do not downgrade only one Highway package.

React 18, CommonJS, direct React-component execution in other frameworks, full Next.js integration, physical-device keyboards and real assistive-technology certification are not claimed. The styles package is usable independently of React.
