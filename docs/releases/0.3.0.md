# Highway 0.3.0

Nine new interaction compositions and corrections to existing action, selection, and toast behavior. The UI remains infrastructure-independent. MCP 0.2.0 serves the matching contracts and examples.

## Install or upgrade

Install the matched public release packages (no checkout or GitHub login required):

```sh
npm install --ignore-scripts --save-exact https://github.com/eythandamico/highway/releases/download/highway-v0.3.0/highway-styles-0.3.0.tgz https://github.com/eythandamico/highway/releases/download/highway-v0.3.0/highway-react-0.3.0.tgz
```

Keep React and React DOM on a matching supported version (19.2+). Import `@highway/styles/styles.css` and wrap adopted content in `HighwayTheme`. No database or infrastructure migration is required. First-adoption tooling is not an upgrade command.

## Behavior to review

- New exports: `Combobox`, `MultiSelect`, `DateRangePicker`, `FilterToolbar`, `InlineEdit`, `ButtonGroup`, `SplitButton`, `CopyButton`, and `CommandPalette`.
- `ActionButton` now awaits `onAction`. Return the real operation promise. Rejection retains a retryable action and announces failure. `loadingDuration` is retained as a deprecated prop but does not manufacture completion; a button without an action no longer simulates success.
- `Button` preserves keyboard focus during loading using `aria-disabled`, and blocks click activation in capture and bubble phases. Explicit `disabled` retains native disabled behavior. Optional `animateLabel` and `reserveLabels` use reduced-motion-aware content transitions without observers. Host form submission handlers must still guard pending submissions.
- `Table` keeps selection attached to stable keys. Supply `rowKey` for mutable datasets; `id` is inferred when available, otherwise original input index is the compatibility fallback. `onSelectionChange` still returns original input indices. New `selectedKeys`/`onSelectedKeysChange` use stable keys. Sorting can be controlled with `sort`/`onSortChange`; sorting currently operates over the provided rows.
- `Select` uses the shared Radix selection implementation for keyboard navigation, typeahead, disabled options, form values, nested portals, and focus restoration.
- Toasts pause their remaining time during hover, focus and hidden documents; `duration: 0` persists. An explicit dismiss button is keyboard accessible. Host-provided `action` content stays separate from dismissal.
- Date ranges use local `YYYY-MM-DD` calendar strings, never UTC timestamps. Incomplete input remains editable; invalid order/bounds are visibly flagged; validate completeness in the host before fetching or submitting.
- CommandPalette never registers a global shortcut or performs navigation itself. The host controls opening and supplies actions. Failed commands remain open for retry.

## Control-family refinement

Core controls now share explicit inset, inner-radius, padding, disabled-opacity and travel-duration tokens. Highway's materials and existing motion character remain. Segmented options gain 44px targets, wrapping-aware selection, named groups and optional disabled states; dense host layouts should account for their larger usable height. Slider labels wrap without covering values, selection and switch keyboard feedback is immediate, and hover treatments avoid touch-only devices. The showcase adds `/components/family` for side-by-side review. No infrastructure changes are required.

## Surface-family refinement

Menu rows now share geometry across action, checkbox/radio and submenu variants, including preserved destructive highlighting. Standalone Menu adds a label, disabled items and keyboard navigation. Cards and dialog actions handle long/narrow content; legacy overlays are viewport-bounded. Accordion panels are inert when closed and resize with content. Alerts cancel dismissal timers on unmount. Video cards expose playback controls and honor reduced motion. The bottom sheet suppresses decorative page transforms under reduced motion. Existing specialty durations move into shared tokens at the same values. `/components/surfaces` provides a side-by-side review.

Review dense menu layouts because full-size row targets can increase menu height. Media no longer auto-plays for reduced-motion users; explicit playback remains available.

## Family consistency follow-up

Mixed checkboxes show a minus; choice menus reserve their selection-mark space; split-button triggers use the standard icon target. BottomNav menus support arrows, Home, and End. Modal titles and toasts fit narrow layouts, and toasts honor reduced motion. No public API changes are required. See the [refinement report](../COMPONENT-FAMILY-REFINEMENT.md) for deferred design proposals and validation results.

## Detail restoration supersedes blanket geometry

The later restoration pass removes the blanket Invariant menu, step, segmented, choice, and close-control sizing described earlier in this local candidate’s history. Native buttons retain their established geometry. Invariant components retain authored compact proportions, explicit weight hierarchy, translucent menu variants, and distinct motion recipes. No public API migration is required. See [the full 50-component comparison](../INVARIANT-DETAIL-RESTORATION.md).

## Validation and rollback

Run `npm run verify:full` before release and validate the actual host workflow after adoption. Browser emulation does not establish real-device or assistive-technology compatibility. See the [interaction validation report](../INTERACTION-VALIDATION.md) for actual results.

Retain the previous matched tarballs and host lockfile. Roll back React/styles together if host validation fails. No persisted-data rollback is needed. Publication and deployment remain manual.

### Agent tools

Added `VoiceRecorder`, `ContextTray`, and `ReviewApplyCard` as package-owned compositions. Recording is local with playback, pause/resume, cleanup and async attachment; context is controlled and inspectable; review/apply waits for host confirmation and retains failures for retry. The showcase, checked examples and MCP interaction guide document the same exported APIs. Microphone use requires browser support, permission and a secure context. No AI provider or backend is bundled.

VoiceRecorder now uses a compact hold-to-record capsule with slide-to-discard, tap/keyboard controls, Prompt Bar-style rounded audio bars and a label-free playback waveform with pointer and keyboard seeking. Playback bars come from the recorded audio; a flat seek track remains available if decoding fails. Its public callback API is unchanged.
